# Experiment summaries

These CSV files are preserved as evidence for exploratory results. **They are not a single combined benchmark**: metrics, targets, and run counts differ across experiments.

- `flock_experiment_2_summary.csv`: 100-run formation ablation.
- `flock_experiment_3_summary.csv`: 100-run pioneer-strategy comparison.
- `flock_experiment_4_summary.csv`: 100-run posterior-functional comparison.
- `experiment5_complete_visible_reps_summary.csv`: summary of **25 complete visible replicate blocks**, not the full planned run.
- `importance_pilot_reported_prior_analysis_UNVERIFIED.csv`: **secondary, unverified** 10-run report. Do not treat as checked raw output.

For definitions, fitted targets, and interpretation see [simulation investigations](../docs/experiments.md). For provenance and missing evidence see [RESULTS_PROVENANCE.md](../RESULTS_PROVENANCE.md).

No claim of reproducibility from these aggregates alone is made.
